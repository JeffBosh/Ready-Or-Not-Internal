NULVEX.ONE - READY OR NOT
=========================

Compatibility
-------------
- Windows x64
- Ready or Not 5.3.2
- DirectX 11 and DirectX 12
- Intended for offline play and private sessions
- Steam

Using the loader
----------------
1. Start Ready or Not.
2. Run Nulvex.exe.
3. Select DX11 or DX12 to match the game session.
4. Select NULVEX, then choose LOAD NULVEX.
5. Press INSERT in game to open or close the menu.
6. Press END to save settings and unload the module.

The Nulvex internal module and Dumper-7 are embedded in Nulvex.exe. No loose
DLL files are required. Settings and logs are stored in %LOCALAPPDATA%\Nulvex.
